# Brand Kit OS plugins for Claude

One marketplace, two plugins. Add `NicT89/brand-kit-os-plugin` in Claude and install what you need.

| Plugin | What it is |
|---|---|
| [brand-kit-os](plugins/brand-kit-os/README.md) | The main plugin. Connects your Brand Kit OS brand kits to Claude, loads brand context and enforces brand voice. |
| [brand-kit-os-labs](plugins/brand-kit-os-labs/README.md) | Experimental skills you can opt into. Needs the main plugin. |
