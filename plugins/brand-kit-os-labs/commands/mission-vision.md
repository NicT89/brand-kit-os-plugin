# /brand-kit-os-labs:mission-vision

Use the `mission-vision-builder` skill to create or rewrite the mission and vision for the brand kit named in `$ARGUMENTS`. If no kit is named, list the user's kits with `get_agent_briefing` and ask which one.

Follow the skill's steps in order: read the kit, find the four raw materials, draft options, test them, present with a recommendation, and save only after the user approves.
